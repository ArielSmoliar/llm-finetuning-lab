# LLM Fine-Tuning Lab

Hands-on learning in supervised fine-tuning, preference optimization, reinforcement learning, evaluation, alignment, and monitoring.

## Getting started

Run notebooks in Google Colab. Save notebook versions to this repository and keep model checkpoints in Google Drive.

The first setup notebook will be saved from Colab as `notebooks/01_stack_setup.ipynb`.

## Experiment notes

For each experiment, record the question, prediction, configuration, results, failure analysis, and next decision. Distinguish planned experiments from completed runs.

Keep access tokens and private data out of notebook code and outputs before committing.
